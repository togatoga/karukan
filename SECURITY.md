# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

As an Input Method Editor (IME) processing keystrokes, we take privacy and security very seriously. If you identify a security vulnerability, please do **not** open a public issue. 

Please report vulnerabilities privately by emailing the repository owner or using GitHub's private vulnerability reporting feature. 

We will acknowledge your report within 48 hours and work to release a patch swiftly.
