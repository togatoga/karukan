# Key Bindings

Karukan のキーバインド一覧です。共通キーバインドは Linux (fcitx5) / macOS の両方で使えます。

## ひらがな入力モード

| キー | 動作 |
|------|------|
| 文字キー | ローマ字入力 → ひらがな変換 |
| Space / ↓ | かな漢字変換を開始 |
| Tab | かな漢字変換を開始（学習履歴を使わない） |
| Enter / Ctrl+M | ひらがなのまま確定 |
| Escape | 入力をキャンセル（ライブ変換中は1回目でライブ変換を解除してひらがなに戻り、2回目でキャンセル） |
| Backspace / Ctrl+H | 1文字削除 |
| Delete | カーソル位置の文字を削除 |
| ← → | カーソル移動 |
| Home / End | カーソルを先頭 / 末尾に移動 |
| Ctrl+B / Ctrl+F | カーソル移動（Emacs風 ← →） |
| Ctrl+A / Ctrl+E | カーソルを先頭 / 末尾に移動（Emacs風） |
| Ctrl+1〜9 | 表示中の候補を番号で選択・確定（文節に分かれているときは、選んで次の文節へ進む） |
| Ctrl+J | カーソル位置までの変換結果を固定する（続きを入力しても左側が変化しなくなる。[詳細](chunking.md)） |
| Ctrl+K | 入力全体を全角カタカナに変換（F7 と同じ） |
| Ctrl+I | 変換を開始して🤖AI候補のビューを直接開く |
| Ctrl+T / Ctrl+R | 変換を開始してソース絞り込みビューへ（Ctrl+T は📝学習から、Ctrl+R は🔄記号変換から） |
| Ctrl+S | 変換を開始して文節に分ける（Space → Ctrl+S と同じ。[詳細](segments.md)） |
| Shift+Space | 全角スペースを入力。入力中は設定した幅の空白を挟む（[詳細](symbols.md)） |
| F6 / F7 / F8 | 入力全体をひらがな / 全角カタカナ / 半角カタカナに変換 |
| F9 / F10 | 入力全体を全角 / 半角英数に変換（打ったキーそのまま。`si` で打った「し」は `si`）。続けて押すと 小文字 → 大文字 → 先頭だけ大文字 を巡回 |

未入力の状態で `:` を打つと絵文字モードになり、`:smile` のようなクエリで絵文字を検索できます。Enterで先頭の絵文字候補を確定、Escapeで入力した文字列をそのまま確定します。

`Ctrl+1〜9`・`Ctrl+J`・`Ctrl+I`・`Ctrl+T` / `Ctrl+R`・`Ctrl+S`・`F6〜F10`・`Ctrl+K` は変換モードでも使えます。

カタカナ入力モードはありません。カタカナにしたい語は、ひらがなで打ってから F7 か Ctrl+K で変換します。確定すると次の語はひらがなに戻ります。どちらのモードでも「いま画面に出ているもの」に対して働きます。

## 変換モード

| キー | 動作 |
|------|------|
| Space / Tab / ↓ / Ctrl+N | 次の候補 |
| ↑ / Shift+Space / Shift+Tab / Ctrl+P | 前の候補 |
| PageDown / PageUp | 候補ページの移動 |
| Ctrl+1〜9 | 表示中の候補を番号で選択・確定 |
| Enter / Ctrl+M | 選択中の候補を確定（文節に分かれているときは全文節をまとめて確定） |
| Escape | 変換をキャンセル（ひらがなに戻る） |
| Ctrl+Backspace / Ctrl+Delete | 選択中の学習候補を履歴から削除 |
| Ctrl+J | カーソル位置で区切り、別候補が出る範囲を狭める（絞り込み中も表示は維持。[詳細](chunking.md)） |
| Ctrl+I | 🤖AI候補のビューを直接開く |
| F6〜F10 / Ctrl+K | 入力全体をひらがな / 全角カタカナ / 半角カタカナ / 全角英数 / 半角英数に変換。候補はこの5種だけになり、モデルは動かない。ひらがな・カタカナの確定は学習され、英数は学習されない |
| Ctrl+T / Ctrl+R （次 / 前） | 候補をソース別に絞り込み（📝学習→📚辞書→🤖AI→🔄記号変換をローテーション。📚はユーザー辞書とシステム辞書の両方で、ユーザー辞書が先。🔄は先頭に📅日付・時刻（きょう等の登録フレーズのみ、[詳細](date.md)）、[単漢字](single-kanji.md)の後ろに素のひらがな/カタカナも並ぶ。全体に戻るには Esc→Space） |
| 文字キー・数字 | 確定せず読みを伸ばして変換をやり直す（インクリメンタルに候補が更新される。ソース絞り込み中はフィルタを維持したままビュー内で候補が絞られ、補助テキストに入力中の読みが表示される） |
| Backspace / Ctrl+H | 変換をキャンセルして入力編集に戻る（Escapeと同様）。ソース絞り込み中は読みを1文字縮めてビューに留まり、候補が広がる |
| Ctrl+S | 変換結果を文節に分ける。もう一度押すと別の区切り方に切り替える（辞書の最長一致 → 字種 → 辞書の最短一致。[詳細](segments.md)） |
| ← → / Ctrl+B・F | 注目する文節を移動（全体のまま押すと、そこで文節に分かれる） |
| Home / End / Ctrl+A・E | 最初 / 最後の文節に移動 |
| Shift+← / Shift+→ | 注目中の文節を1文字縮める / 伸ばす |

## モード切り替え

| キー | 動作 |
|------|------|
| Shift+英字 | 英数字モードに切り替え + 大文字入力 |
| Ctrl+I | 変換を開始して🤖AI候補のビューを直接開く |
| Ctrl+T / Ctrl+R | 変換を開始してソース絞り込みビューへ（Ctrl+T は📝学習から、Ctrl+R は🔄記号変換から） |
| Ctrl+Shift+L | ライブ変換のON/OFF |

### 設定の切り替え

設定の名前を打って変換すると、候補の 2 番目に設定を切り替える候補が出ます。選んで確定すると、文字は入力されずに設定だけが切り替わります。キーを奪わないので、アプリのショートカット（ターミナルの Ctrl+Shift+V での貼り付けなど）はそのまま使えます。

| 読み | 候補 | 切り替わる設定 |
|------|------|----------------|
| でばっぐもーど（でばっくもーど でも可） | 【デバッグモードをオン】/【デバッグモードをオフ】 | 補助テキストの詳細表示（[設定](configuration.md#詳細表示verbose)） |

### 英数字モード

英数字モードでは文字がローマ字変換されず、そのまま入力されます。日本語と英語を混ぜて入力し、Spaceで変換するとひらがな部分のみ変換されます。

例: `わたしはLinuxが` → 変換 → `私はLinuxが`

## Linux (fcitx5) 固有

| キー | 動作 |
|------|------|
| 右Super・右Altなど右側の修飾キー / 変換 (JIS) | 英数字モード → ひらがなモードに復帰 |

## macOS 固有

| キー | 動作 |
|------|------|
| かな (JIS) | Shift+英字で入った英数字モードからひらがな入力モードへ戻る（Linux版の右Super/変換キーに相当） |
| 英数 (JIS) | 変換中テキストを確定して直接入力モードへ切替 |
| 右⌘ 単独タップ | かなキーと同じ（ひらがな入力モードへ戻る）。JISかなキーが無いUS配列向けの代替で、Karabinerなどの設定は不要。⌘C など他のキーと組み合わせた場合や、他の修飾キーと同時押しした場合は発動しない |
