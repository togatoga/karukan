# ローマ字テーブル

`~/.config/karukan-im/romaji.tsv` を置くと、組み込みのローマ字規則の代わりにそのテーブルで入力します。形式は azooKey / hazkey のローマ字テーブルと同じなので、hazkey 用に作ったテーブル（独自配列や、かな配列風のもの）をそのまま使えます。

```
d	ｄ
ｄh	か
ｄu	きゃ
きゃu	きゃあ
```

1行に `キー<TAB>出力` を1組書きます。`{` と `}` は azooKey と同じく `{lbracket}` `{rbracket}` と書きます。ファイルが無いか空のときは組み込みの規則（通常のローマ字入力）のままです。読み込むのは起動時だけなので、変更したら `fcitx5 -r` で再起動してください。

## 規則の当て方

キーは打ったキーの並びではなく、入力中の文字列の末尾と照合します。1キー打つごとに、末尾に一致する最も長いキーをその出力に置き換えます。そのため、ある規則の出力を次の規則のキーに使えます。

```
d     → ｄ        (d → ｄ)
dh    → か        (ｄh → か)
du    → きゃ      (ｄu → きゃ)
duu   → きゃあ    (きゃu → きゃあ)
```

まだ書き換わる可能性のある末尾（いずれかのキーの途中まで一致している部分）だけが入力途中として残り、それより前は確定します。上の例の「きゃ」は表示されたまま、続く `u` で「きゃあ」に置き換わります。

## 組み込みの規則との違い

テーブルを使うときは、組み込みの規則に固有の処理は行いません。

- `n` + 子音で「ん」、同じ子音の連続で「っ」になる処理はありません。必要ならテーブルに書きます。
- [記号・半角全角](symbols.md) の `[width]` と `[symbol]` は適用されず、テーブルに書いた文字がそのまま入力されます。半角の `1.` や `:-` のような ASCII の出力も書いたとおりに出ます。
