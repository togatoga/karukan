# 記号・半角全角

「句読点は `、。` か `，．` か」「記号は半角で出したい」「スペースは常に半角がいい」といった設定です。`config.toml` の `[symbol]`（どの記号を打つか）と `[width]`（どの幅で出すか）の2つに分かれています。

```toml
[symbol]
punctuation = "、。"    # 「,」「.」キーが入力する句読点
bracket = "「」"        # 「[」「]」キーが入力する括弧
slash = "・"            # 「/」キーが入力する記号
space = "half"          # スペースキーが入力する空白

[width]
kana_symbol  = "full"   # 。、「」・
ascii_symbol = "full"   # ?! ,. (){}[] <>=+-/* "' :; ~ #%&@$^_|`\
digit        = "half"   # 0-9
```

かな入力中の出力は既定で全角、数字だけ半角です。英字モード（Shift+英字）と絵文字モードは対象外で、打ったとおりの半角が出ます。

## どの記号を打つか（`[symbol]`）

キーによっては打てる記号が複数あります。どれを打つかをここで選びます。

| 設定 | 対象キー | 選択肢 |
|---|---|---|
| `punctuation` | `,` `.` | `"、。"` / `"，．"` / `"、．"` / `"，。"` |
| `bracket` | `[` `]` | `"「」"` / `"[]"` |
| `slash` | `/` | `"・"` / `"/"` |

たとえば `punctuation = "，．"` にすると、`,` は 、 ではなく ， を入力します。論文や技術文書で `，．` を使う場合の設定です。

`Ctrl+/`（`z/` → `・`）のような Z キー記号は、この設定に関係なく固定です。

## どの幅で出すか（`[width]`）

文字の種類（グループ）ごとに `"half"`（半角）か `"full"`（全角）を指定します。切り替えた結果は次のとおりです。

| グループ | 対象文字 | `"full"` | `"half"` |
|---|---|---|---|
| `kana_symbol` | かなと組で使う記号 | 。、「」・ | ｡､｢｣･ |
| `ascii_symbol` | ASCII 由来の記号 | ？！，．（）［］｛｝＜＞＝＋－／＊＂＇：；〜＃％＆＠＄＾＿｜｀＼ | ?!,.()[]{}<>=+-/*"':;~#%&@$^_\|`\ |
| `digit` | 数字 | １２３ | 123 |

### グループの分け方

`。、「」・` は ASCII に対応する文字がない記号です。半角形は `｡ ､ ｢ ｣ ･` しかなく、これは半角カタカナと同じ字形（`ｱｲｳ｡` のようにかなと組で使うもの）です。`kana_symbol` という名前はここから来ていて、`ascii_symbol` とは ASCII 由来かどうかで分かれています。

分けているのは、いちばん使いたい `ascii_symbol = "half"`（記号は半角に）が `。` まで巻き込むと 「こんにちは｡」 になってしまうからです。分けておけば 「こんにちは!」 で済みます。`？！` が `ascii_symbol` 側にいるのも同じ理由で、`？` は `?` の全角形だからです。

逆に「`(` は半角だが `@` は全角」を求める人はいないため、ASCII の記号は `ascii_symbol` ひとつにまとめています。英字に設定がないのは、かな入力中の英字が「入力途中のローマ字（`わせだd` の `d`）」か「辞書の表記」のどちらかで、どちらも勝手に幅を変えるものではないからです。全角の英字が欲しいときは候補一覧の `ＡＢＣ`（`[全]英大文字`）から選べます。

### かな入力にだけ適用される

幅の設定が効くのは**かな入力中**（ひらがな・カタカナモード）だけです。英字モード（Shift+英字）と絵文字モードでは適用されず、打ったとおりの半角が出ます。かな入力は全角、直接入力は半角、という日本語IMEの分け方です。

そのため `ascii_symbol = "full"`（既定）でも、英字モードで `Hello, world.` と打てば `Hello, world.` のままです。

### 既定値

| グループ | 既定 | 理由 |
|---|---|---|
| `kana_symbol` | `full` | `。、「」・` は全角が日本語の表記 |
| `ascii_symbol` | `full` | かな入力の記号は全角（`(a)` → `（あ）`）。ローマ字ルールのある `？！` だけ全角で、`(` `@` は半角、という従来の混在をなくす |
| `digit` | `half` | 確定するたびに選んだ幅を覚える仕組みがないため、全角固定は取り消しがきかない。数字は半角で使う場面のほうが多い |

### 「記号はすべて半角で出力する」

```toml
[width]
symbol = "half"
```

この設定で `konnnichiha!` と打つと `こんにちは!` が確定します（`！` ではなく `!`）。`(a)` は `(あ)` です。句読点 `。、` は `japanese` が担当するのでそのままです。

### 「数字も全角にする」

```toml
[width]
digit = "full"
```

`heya123` と打つと `へや１２３` になります。

## どこに適用されるか

幅は次の2箇所で適用されます。

**打った文字は、打った時点で確定します。** そのため英字モード（Shift+英字）に切り替えても、それ以前に打った `（` はそのまま残ります（`（A` になります）。英字モード中に打った文字には適用されません。

**AI変換の結果は、受け取った時点で揃えます。** モデルに渡すプロンプトは NFKC 正規化されるため、`！` と打っても変換結果は `!` で返ってきます。ここで揃えないと、設定した幅が変換のたびに失われます。

この2つで、次のどれも同じ幅で出るようになります。

- 入力した記号（`(` → `（`）
- AI変換の結果に含まれる記号（ライブ変換の `!`）
- 変換にかからず通過した記号や数字（`(1)`）

逆に、**誰かが選んだ表記は変えません**。AI変換の結果だけが「プロンプトの正規化でそうなっただけ」の幅なので揃える対象です。

**候補一覧の幅バリエーション**。記号・数字だけの入力には、**設定どおりの形・まるごと全角・まるごと半角の3つ**が候補に並びます。

```
<>1234 と入力（既定の設定）
  ＜＞1234      ← 設定どおり（記号は全角、数字は半角）
  ＜＞１２３４   [全]記号
  <>1234        [半]記号
```

注釈で形が見分けられるので、設定と違う幅を1回だけ使いたいときはここから選べます。記号に名前がある場合は `＠` → `[全]アットマーク` のように、幅の印を名前の前に付けます。

**ユーザー辞書に登録した表記**。`(株)` を半角で登録したなら、`ascii_symbol = "full"` でも `(株)` のまま出ます。システム辞書は一般の語彙データなので設定に揃えます。

ただし幅を揃えた結果、バリエーションが他の候補と同じ表記になった場合は重複として1つにまとめられます。`digit = "full"` のときの `1` とバリエーションの `１` は、どちらも `１` になるため候補は1つだけです。候補の番号（Ctrl+数字）も詰められた後の並びと一致します。

## スペース

`[symbol] space` は、かな入力中にスペースキーが入力する空白を決めます。`"half"`（既定）か `"full"` の2択です。

| キー | 何も入力していないとき | 入力中（変換前） |
|---|---|---|
| Space | 設定した幅 | 変換を開始する |
| Shift+Space | **全角**（設定に関わらず） | 設定した幅 |

入力中は Space が変換にあたるため、そこに空白を挟むときは Shift+Space を使います。こちらも設定に従うので、既定のままなら半角スペースを含んだ文をそのまま変換できます。

単独の Shift+Space だけが例外で、設定に関わらず全角スペースを入力します。「基本は半角、ここだけ全角」という使い方のためのものです。

英字モード・絵文字モードでは設定に関わらず半角スペースです（幅の設定と同じで、直接入力には効きません）。半角スペースになる場面では、入力していない状態のスペースキーはアプリケーションにそのまま渡されます（ブラウザのページ送りなどが従来どおり動きます）。

AI変換の結果に含まれる空白もこの設定に揃えます。モデルに渡すプロンプトは NFKC 正規化されて全角スペースが半角になるため、モデル側は全角スペースを返せないからです。

## 設定の反映

設定変更後は fcitx5 の再起動（macOSは `killall KarukanIME`）で反映されます。
