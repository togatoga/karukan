# 日付・時刻の変換

「きょう」「あした」「いま」などを変換すると、その日付・時刻の候補が出ます。フレーズと出力形式は `config.toml` の `[date]` で自由に登録できます。

```
きょう → 2026/09/06・2026-09-06・2026年9月6日・令和8年9月6日・9月6日・9月6日(日)・日曜日
あした → 2026/09/07 …（同じ形式で翌日）
いま   → 15:30・15時30分・午後3時30分
にちじ → 2026/09/06 15:30・2026年9月6日15時30分
```

候補は候補一覧の後方（📅）に並びます。`Ctrl+R` で開く変換ビュー（🔄。幅・記号などの変換候補と同居）では先頭に並びます。確定しても学習履歴には記録されません。日付は明日には古くなるので、記録すると「きょう」の変換に昨日の日付が出続けてしまうためです。

## フレーズの登録（`[date]`）

フレーズは**読み**（`reading`）、**今日から±何日か**（`offset_days`、省略時は 0）、**出力形式**（`formats`、複数可）を持ちます。`formats` を書かないフレーズは共有の `[date] formats` を使うので、日付フレーズは1行で済みます。

```toml
[date]
formats = [               # formats を持たないフレーズが共通で使う
    "{YEAR}/{MONTH}/{DATE}",
    "{YEAR}年{MONTH:bare}月{DATE:bare}日",
]
phrases = [
    { reading = "きょう", offset_days = 0 },
    { reading = "あした", offset_days = 1 },
    { reading = "らいしゅう", offset_days = 7 },
    { reading = "いま", formats = ["{HOUR}:{MINUTE}"] },   # 自前の formats を持つフレーズ
]
```

既定で きょう・きのう・おととい・あした・あす・あさって・しあさって（日付）、いま（時刻）、にちじ（日時）が登録されています（正確な既定値は [`config/default.toml`](../karukan-im/core/config/default.toml) 参照）。

`phrases` を書くと既定の一覧は**丸ごと置き換わります**。フレーズを増やしたり一部だけ変えたりするときは、default.toml の一覧をコピーして編集してください。使わないフレーズは行ごと消せば無効になります。

## 出力形式（フォーマット）

`{トークン}` の部分が日時に置き換わり、それ以外はそのまま出ます。

| トークン | 出力例 | 説明 |
|---|---|---|
| `{YEAR}` | 2026 | 西暦4桁 |
| `{MONTH}` | 09 | 月（2桁ゼロ埋め） |
| `{DATE}` | 06 | 日（2桁ゼロ埋め） |
| `{HOUR}` | 05 | 時（24時間・2桁ゼロ埋め） |
| `{MINUTE}` | 08 | 分（2桁ゼロ埋め） |
| `{ERA}` | 令和 | 元号（明治まで） |
| `{ERA_YEAR}` | 8 | 元号の年 |
| `{WEEKDAY}` | 土 | 曜日。「曜日」まで欲しければ `{WEEKDAY}曜日` |
| `{HOUR12}` | 3 | 時（12時間）。深夜0時は午前0時、正午は午後0時 |
| `{AMPM}` | 午後 | 午前/午後 |
| `{{}` | { | 「{」そのもの |

### ゼロ埋めなし・漢数字にする

数値トークンには `:` に続けてスタイルを指定できます。「09月」ではなく「9月」にしたい、漢数字で出したい、という部分ごとの指定です。

| スタイル | 例 | 出力 |
|---|---|---|
| なし | `{MONTH}月` | 09月 |
| `:bare` | `{MONTH:bare}月` | 9月 |
| `:kanji` | `{MONTH:kanji}月` | 九月 |

`:kanji` は年だけ桁ごと（`{YEAR:kanji}` → 二〇二六）、それ以外は読み下し（`{DATE:kanji}` → 十六）で出ます。`{ERA_YEAR:kanji}` の1年は「元」になり、`{ERA}{ERA_YEAR:kanji}年` が「令和元年」になります。もともとゼロ埋めのないトークン（`{HOUR12}` `{ERA_YEAR}`）では `:bare` は無指定と同じです。

```toml
[date]
phrases = [
    { reading = "きょう", formats = [
        "{YEAR:kanji}年{MONTH:kanji}月{DATE:kanji}日",           # 二〇二六年九月六日
        "{ERA}{ERA_YEAR:kanji}年{MONTH:kanji}月{DATE:kanji}日",  # 令和八年九月六日
    ] },
]
```

存在しないトークンやスタイルを含む形式は、壊れた文字列を出す代わりにその候補ごとスキップされます（`{ERA}` や `{YEAR}` を含む形式は明治より前・西暦1年より前の日付でもスキップ）。

## 設定の反映

設定変更後は fcitx5 の再起動（macOS は `killall KarukanIME`）で反映されます。
