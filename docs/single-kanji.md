# 単漢字変換

読み全体を漢字1文字に変換する候補です。「たか」を変換すると、モデルや辞書が出す候補とひらがな・カタカナのあとに、その読みを持つ漢字が1文字ずつ並びます。人名の「髙」や旧字の「國」、珍しい訓読みのように、モデルも辞書も出さない字を拾うための候補です。

```
たか   → （学習・辞書・AIの候補）… たか・タカ・（たか と読む漢字が1字ずつ）・ﾀｶ
あいだ → あいだ・アイダ・間・ｱｲﾀﾞ
```

## 候補の位置

単漢字は 🔄（記号・絵文字・幅などの変換候補）に含まれます。候補一覧（Space）では、読みそのものを指す記号や絵文字（ひょう → 🐆）の後ろ、半角カタカナ（ﾀｶ）の前に並びます。「か」のように短い読みでは数が多くなるため、よく使う字は上のソースから出る前提で後ろにまとめてあります。`Ctrl+R` で開く🔄ビューでも同じ順で、単漢字の後ろにタカ・ﾀｶ・たかが来ます。

読みはデータにあるものとの完全一致だけを引きます。「たか」には出ますが、「たかさ」には出ません。

## 注釈

旧字体や異体字には「高の異体字」のような注釈が付きます。学習や辞書が同じ字を出したときも、その字に同じ注釈が付きます。

## 学習との関係

確定した字は学習に記録され、次からは📝学習として先頭に出ます。一度でも確定した字は、別の読みでも単漢字の列の先頭に上がります。「こう」で「高」を確定していれば、「たか」の列でも「高」が先頭です。使った字から順に並び、使ったことのない字はファイルの順のままです。並べ替えは単漢字の列の中だけで、記号や半角カタカナの位置は変わりません。

## データの形式

候補は [`karukan-engine/data/single_kanji.yml`](../karukan-engine/data/single_kanji.yml) に、漢字1字につき1エントリで入っています。

```yaml
entries:
  - char: 高
    readings: [こ, こう, たか, だか]
  - char: 髙
    readings: [こう, たか]
    description: 高の異体字     # 省略可。候補の横に出る注釈
```

`readings` はその字を出す読みの一覧で、いくつでも書けます。同じ読みの中ではファイルで上にあるエントリが先に出るので、よく使う字を上に、珍しい字を下に置きます。同じ字が2回出てきたら読みは合算され、注釈は先に書いたものが残ります。読みを持たず `description` だけのエントリも書けます。他のソースが出した字に注釈を付けるためだけのエントリです。

ファイルはビルド時にバイナリへ埋め込まれるので、編集後はビルドし直してください。
