# 学習

karukan は、変換したときに何が起きたかを覚えて、次の変換に使います。覚えたことは候補の並びだけでなく、入力中のライブ変換の表示そのものにも効きます。

## 何を覚えるか

覚える単位は「読みの一続き」と「表記」の組（例: `あんそろぴっく` と `Anthropic`）です。組ごとに、起きた出来事を種類ごとに数えます。

| 出来事 | いつ | 重み |
|---|---|---|
| 選んだ (chosen) | 既定として表示されていたものと違う候補を選んで確定した | +1.0 |
| 確かめた (confirmed) | 一覧を開いたり文節に注目したりしたうえで、既定のまま確定した | +0.4 |
| そのまま確定した (accepted) | ライブ変換の表示をそのまま Enter で確定した | +0.1 |
| 差し替えた (displaced) | 既定として表示されていたのに、別の候補に替えた | −1.0 |

「既定」は、Space を押した時点で画面に出ていた文字列（ライブ変換の表示）です。ライブ変換がオフなら一覧の先頭です。

- 文のまま選んでも、違いが 1 か所だけならその語も覚えます。`今日は医者に行く` を `今日は慰謝に行く` に選び直すと、文全体に加えて `いしゃに` → `慰謝に` を半分の重みで覚えます
- ライブ変換をそのまま確定したときは、入力全体を「そのまま確定した」として覚えます（入力中の予測に使います）。内部の区切り（Chunk）や置き換えた範囲は、すでに覚えている組なら「そのまま確定した」を足して新しくするだけで、新しくは覚えません。AI の出力そのものを覚えても、AI がまた同じものを出すだけだからです
- 文節に分けた変換では、注目して一覧を開いた文節だけを覚えます。注目しなかった文節は、読みとの対応が推測なので覚えません
- 入力中の候補を Ctrl+数字で選んだときは、ライブ変換の表示と比べます
- 日付・バージョン・コマンド、F9/F10 の英数は覚えません

数は時間とともに薄れます（30 日で半分）。最近よく使うものほど強く効きます。

それぞれの組には「文脈」ごとの内訳も最大 4 つ持ちます。文脈は、その組の左側で打った読みの末尾 2 文字です（`ごはんを｜はし` なら `んを`）。入力の先頭なら、入力欄でカーソルの前にある文字の末尾 2 文字です。表示は AI や置き換えで変わりますが、打った読みは変わらないので、読みを使います。右側は使いません。ライブ変換中は打つたびに変わるからです。同じ読みでも、`試験の` のあとでは `解答`、`質問へ` のあとでは `回答` のように使い分けられます。

## 点数

組の点数は次のとおりです。文脈が一致すれば、その内訳を同じ式で足します。

```
点数 = 1.0 × 選んだ + 0.4 × 確かめた + 0.1 × そのまま確定した − 1.0 × 差し替えた
```

## どう効くか

### ライブ変換の表示

入力中、AI の変換結果のうち、履歴にある読みと一致する文節の並び（または区切り全体）を、履歴の表記に置き換えます。文節は助詞込みで区切られるので、末尾の助詞を外しても照合します。置き換えるのは次のどちらかのときだけです。

1. 同じ左の文脈でその表記を選んだことがある。その文脈の内訳だけで比べて、AI の表記を 0.3 より多く上回るとき
2. 違う文脈で 2 回以上その表記を選んでいる（どこでもその書き方が好き、とみなす）。全体の点数で比べて、AI の表記を 0.3 より多く上回るとき

それ以外（ほかの文脈で 1 回選んだだけ、など）は置き換えず、候補の並びにだけ使います。1 文字の読みは置き換えません。

例:

- ライブ変換で `アンソロピック` と出たのを、一覧から `Anthropic` に選び直して確定すると、次からは `あんそろぴっく` が `Anthropic` と表示されます。`あんそろぴっくのもでる` も `Anthropicのモデル` になります（どちらも入力の先頭なので、同じ文脈です）
- `ごはんを｜はしで` で `箸` を選んでも、`かわにかかる｜はし` は `橋` のままです
- `うちの｜こども` と（入力の先頭の）`こどもが` の 2 つの文脈で `子ども` を選ぶと、どこでも `子ども` になります

置き換えが外れたときのために:

- 置き換えた表示は学習の候補（📝）として先頭に出し、AI の元の結果（🤖）をそのすぐ次に置きます。入力中の候補（Ctrl+数字）でも Space の一覧でも同じです。文節に分けたときも、置き換えた範囲を含む文節の一覧に元の表記が入ります
- 元の結果を選んで確定すると、置き換えた範囲について元の表記が「選んだ」、置き換えた表記が「差し替えた」になり、次からその文脈では置き換わりません。選び直しは向きが逆なら打ち消し合うので、`箸` と `橋` を 1 回ずつ選べば AI の既定に戻ります
- 置き換えた表示を選んで `Ctrl+Backspace` を押すと、置き換えの元になった組を履歴から消します
- 置き換わった表示をそのまま確定しても「そのまま確定した」（弱い証拠）しか増えないので、置き換えが自分を強めることはほとんどありません
- 英字の直接入力（Shift+英字）と絵文字の入力中は置き換えません

### 候補の並び

- 学習の候補（📝）は点数の順に並びます。点数が 0 以下のもの（選ぶより差し替えた方が多いもの）は学習の候補として出しません
- 一度も選んだり確かめたりしていない組（そのまま確定しただけのもの）は、一覧の先頭に出しません。入力中の予測（読みの続きの候補）にだけ使います
- 文節の一覧では、前の文節を文脈にして並べます
- Space の一覧の AI の別候補は、各候補を文節に分けて文節ごとの点数を足した値の順に並べます。先頭は画面に出ていた文字列のままです

## 保存と削除

- 保存先: `~/.local/share/karukan-im/learning.tsv`（macOS: `~/Library/Application Support/com.karukan.karukan-im/learning.tsv`）
- IME の切り替えやウィンドウの切り替えのときに保存します（確定のたびには保存しません）
- 組の数が `max_entries`（既定 10,000）を超えたら、証拠の少ないものから消します
- 変換中に学習候補（📝）を選んで `Ctrl+Backspace`（macOS では Ctrl+delete、`Ctrl+Delete` でも可）を押すと、その組を履歴から消せます
- 履歴をすべて消すには `learning.tsv` を削除します

### ファイルの形式

先頭行が `# karukan learning cache v2` で、各行の 1 列目が行の種類です（タブ区切り）。

```
U	読み	表記	更新時刻	選んだ	確かめた	そのまま確定した	差し替えた
C	読み	表記	文脈	更新時刻	選んだ	確かめた	そのまま確定した	差し替えた
B	読み	位置	更新時刻	値
```

`C` は組の文脈ごとの内訳、`B` は文節の区切りを動かした位置です（形だけ用意したもので、いまはまだ書き込みも使いもしません）。以前の形式（`読み 表記 回数 最終使用時刻` の 4 列）のファイルもそのまま読み込めます。種類が分からないので「確かめた」として取り込み、次の保存で新しい形式になります。
