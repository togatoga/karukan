# 学習

karukan は、変換したときに何が起きたかを覚えて、次の変換に使います。覚えたことは候補の並びだけでなく、入力中のライブ変換の表示そのものにも効きます。

## 何を覚えるか

覚える単位は「読みの一続き」と「表記」の組（例: `あんそろぴっく` と `Anthropic`）です。組ごとに、起きた出来事を種類ごとに数えます。

| 出来事 | いつ | 重み |
|---|---|---|
| 選んだ (chosen) | 既定として表示されていたものと違う候補を選んで確定した | +1.0 |
| 確かめた (confirmed) | 一覧を開いたり文節に注目したりしたうえで、既定のまま確定した | +0.4 |
| そのまま確定した (accepted) | ライブ変換の表示をそのまま Enter で確定した | +0.1 |
| 差し替えた (displaced) | 既定として表示されていたのに、別の候補に替えた | −1.0 |

「既定」は、Space を押した時点で画面に出ていた文字列（ライブ変換の表示）です。ライブ変換がオフなら一覧の先頭です。

- 文のまま選んでも、違いが 1 か所だけならその語も覚えます。`今日は医者に行く` を `今日は慰謝に行く` に選び直すと、文全体に加えて `いしゃ` → `慰謝` を覚えます
- 選び直した範囲の端にあって、どちらの表記にも読みのまま残っているかな（`部が` → `分が` の `が`）は、範囲から外して前後の文脈に回します。覚えるのは実際に変わったところ（`ぶ` → `分`）です
- ライブ変換をそのまま確定したときは、入力全体を「そのまま確定した」として覚えます（入力中の予測に使います）。内部の区切り（Chunk）や置き換えた範囲は、すでに覚えている組なら「そのまま確定した」を足して新しくするだけで、新しくは覚えません。AI の出力そのものを覚えても、AI がまた同じものを出すだけだからです
- 文節に分けた変換では、注目して一覧を開いた文節だけを覚えます。注目しなかった文節は、読みとの対応が推測なので覚えません
- 入力中の候補を Ctrl+数字で選んだときは、ライブ変換の表示と比べます
- 日付・バージョン・コマンド、F9/F10 の英数は覚えません

数は時間とともに薄れます（30 日で半分）。最近よく使うものほど強く効きます。

それぞれの組には「文脈」ごとの内訳も最大 8 つ持ちます。文脈は、その組の前に打った読みの末尾 4 文字と、後ろに打った読みの先頭 4 文字の組です（`きょうのしあいは｜ぶ｜がわるい` なら `しあいは` と `がわるい`）。入力の先頭なら、前の読みの代わりに入力欄でカーソルの前にある文字を使います。表示は AI や置き換えで変わりますが、打った読みは変わらないので、読みを使います。同じ読みでも、`試験の` のあとでは `解答`、`質問へ` のあとでは `回答` のように使い分けられます。

## 点数

組の点数は次のとおりです。文脈が 1 文字でも一致すれば、いちばん多く一致した文脈の内訳を同じ式で足します。

```
点数 = 1.0 × 選んだ + 0.4 × 確かめた + 0.1 × そのまま確定した − 1.0 × 差し替えた
```

## どう効くか

### ライブ変換の表示

選び直して覚えた組は、その文脈と合わせて「ルール」になります。入力中、打った読みの中にルールの読みが出てきたら、前後の読みがルールの文脈とどれだけ一致するかを数えます（前は末尾から、後ろは先頭から、続けて一致した文字数）。「ルールの読みの長さ + 前の一致 + 後ろの一致」の合計で、書き換え方が 2 つに分かれます。先に強い書き換え、次に弱い書き換えをかけます。

| | 強い書き換え | 弱い書き換え |
|---|---|---|
| 合計 | 6 文字以上 | 4 文字以上 |
| 当てる相手 | 読み（AI が何と変換したかに関係なく） | AI が変換した結果（AI がその読みに当てた語） |
| 書き換え方 | その範囲をルールの表記で固定し、その後ろは AI で変換し直す | AI が書いた語だけをルールの表記に差し替える |
| 例 | `きょうじゅう` → `今日中`（AI が `教授ウニヤル` と崩しても `今日中にやる`） | `このしょうぶはぶがわ` の `部` → `分` |

どちらも、ルールの点数が AI の表記の点数を 0.3 より多く上回るときだけ当てます。AI の変換結果を文節に分けられるときは、文節の頭から始まるところにだけ当てるので、語の途中には当たりません（`くらぶ` の `ぶ` には当たらない）。合計が 4 文字に足りないものは置き換えず、候補の並びにだけ使います。後ろの読みは打ち終わった分だけを見るので、続きを打つと切り替わることがあります。

例:

- `きょうのしあいは｜ぶが｜わるい` で文節の `部が` を `分が` に直すと、`このしょうぶはぶがわるい` も `この勝負は分が悪い` になります（`ぶ` の 1 文字、前の `は`、後ろの `がわるい` で合計 6、強い書き換え）。`ぶが` まで打った時点では合計 3 で `部が` のまま、`わ` を打つと合計 4 で弱い書き換えになります
- 同じ学習でも、`くらぶがわるい` の `ぶ` は語の途中なので `クラブが悪い` のまま、`ぶがある` は合計 2 なので `部がある` のままです
- `ごはんを｜はし` で `箸` を選ぶと、次の `ごはんをはし` も `箸` になります。`かわにかかるはし` は合計 2 なので `橋` のままです
- ライブ変換で `アンソロピック` と出たのを `Anthropic` に選び直すと、次からは `あんそろぴっく` が `Anthropic` になります。読みが 7 文字あるので、どこに出てきても強い書き換えで当たります

置き換えが外れたときのために:

- 置き換えた表示は学習の候補（📝）として先頭に出し、AI の元の結果（🤖）をそのすぐ次に置きます。入力中の候補（Ctrl+数字）でも Space の一覧でも同じです。文節に分けたときも、置き換えた範囲を含む文節の一覧に元の表記が入ります
- 元の結果を選んで確定すると、当たったルールの文脈で、元の表記が「選んだ」、置き換えた表記が「差し替えた」になり、次からそのルールは当たりません。選び直しは向きが逆なら打ち消し合うので、`箸` と `橋` を 1 回ずつ選べば AI の既定に戻ります
- 置き換えた表示を選んで `Ctrl+Backspace` を押すと、置き換えの元になった組を履歴から消します
- 置き換わった表示をそのまま確定しても「そのまま確定した」（弱い証拠）しか増えないので、置き換えが自分を強めることはほとんどありません
- 英字の直接入力（Shift+英字）と絵文字の入力中は置き換えません

### 候補の並び

- 学習の候補（📝）は点数の順に並びます。点数が 0 以下のもの（選ぶより差し替えた方が多いもの）は学習の候補として出しません
- 一度も選んだり確かめたりしていない組（そのまま確定しただけのもの）は、一覧の先頭に出しません。入力中の予測（読みの続きの候補）にだけ使います
- 文節の一覧では、前後の文節の読みを文脈にして並べます
- Space の一覧の AI の別候補は、各候補を文節に分けて文節ごとの点数を足した値の順に並べます。先頭は画面に出ていた文字列のままです

## 保存と削除

- 保存先: `~/.local/share/karukan-im/learning.tsv`（macOS: `~/Library/Application Support/com.karukan.karukan-im/learning.tsv`）
- IME の切り替えやウィンドウの切り替えのときに保存します（確定のたびには保存しません）。Linux（fcitx5）で入力欄が複数あっても、学習は 1 つを共有するので、ある入力欄で覚えたことはほかの入力欄にもすぐ効き、保存で消し合うこともありません
- 組の数が `max_entries`（既定 10,000）を超えたら、証拠の少ないものから消します
- 確定した直後に `Backspace`（macOS では delete）を押すと、その確定で学習した分がすべて取り消されます（選んだ表記、差し替えた既定、文の中の語、置き換えた範囲に足した分も）。キーはそのままアプリに渡るので、文字も普段どおり 1 文字消えます。取り消せるのは確定の直後に押したキーだけで、ほかのキー（Shift などの修飾キーは除く）を押したり、フォーカスやカーソルが移ったりすると取り消せなくなります。`Ctrl+Backspace` など修飾キー付きの Backspace はアプリのショートカットなので対象外です
- 変換中に学習候補（📝）を選んで `Ctrl+Backspace`（macOS では Ctrl+delete、`Ctrl+Delete` でも可）を押すと、その組を履歴から消せます
- 履歴をすべて消すには `learning.tsv` を削除します

### ファイルの形式

先頭行が `# karukan learning cache v3` で、各行の 1 列目が行の種類です（タブ区切り）。

```
U	読み	表記	更新時刻	選んだ	確かめた	そのまま確定した	差し替えた
C	読み	表記	前の読み	後ろの読み	更新時刻	選んだ	確かめた	そのまま確定した	差し替えた
B	読み	位置	更新時刻	値
```

`C` は組の文脈ごとの内訳、`B` は文節の区切りを動かした位置です（形だけ用意したもので、いまはまだ書き込みも使いもしません）。ひとつ前の形式（先頭行が `v2` で、`C` の行に前の文脈だけがあるもの）も、以前の形式（`読み 表記 回数 最終使用時刻` の 4 列）も、そのまま読み込めます。v2 の文脈は前の文脈として、4 列の行は種類が分からないので「確かめた」として取り込み、次の保存で新しい形式になります。
