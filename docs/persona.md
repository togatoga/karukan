# 変換ペルソナ

よく書く文章と関連のあるキーワードを `config.toml` の `persona` に書くと、それに寄せた変換が出やすくなります。書いたテキストはモデルへ渡す文脈の先頭に毎回付き（間に半角スペースが1つ入ります）、モデルはそれを直前の文章として読みます。

```toml
[conversion]
persona = "プログラミング"
```

| 読み | `persona = ""`（既定） | `persona = "プログラミング"` |
| --- | --- | --- |
| くろーど | クロード | Claude |
| らすと | ラスト | Rust |

ライブ変換・Space変換の両方に効きます。既定は `""` で、何も付けずに変換します。

## 書き方

- 前後の空白を除いた末尾25文字が使われます（10〜20文字推奨）
- 英語で書くこともできますが、英語の直前文脈になるので綴りが小文字に寄ります（`persona = "programming"` では `くろーど` → `claude`、`らすと` → `last`）。正式な綴りで出したいときは日本語で書きます
- 全角英数は半角にそろえて使われます（モデルへの入力は NFKC 正規化されるため。表示も同じ値です）

## 設定したペルソナの確認

`Ctrl+Shift+V` の詳細表示（[設定](configuration.md#詳細表示verbose) 参照）で、補助テキストのモード表示にモデルへ渡している値が付きます（例: `⚡[あ]P:プログラミング`）。通常の表示には出ません。
